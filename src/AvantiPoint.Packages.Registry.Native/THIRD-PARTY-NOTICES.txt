MavenVersionComparer.cs adapts the parsing/comparison algorithm from Apache Maven
3.9.11 org.apache.maven.artifact.versioning.ComparableVersion into C# and uses
BigInteger for all numeric components. This adapted file is Apache-2.0 licensed;
the other new native registry files retain this repository's license.
